# Profile: application-note

## Signals
- "Application Note", "AN-", "Design Guide", "Reference Design", "White Paper", "Tutorial"; a problem statement, a worked design, results.
- Mixed prose with example circuits, calculations, measured plots and code.

## Typical content
- Background and theory; design equations with worked numbers; example schematics; layout advice; measurement results and plots; code listings; bill of materials.

## Custom steps
- **Stage 4:** keep design equations and every worked step with units; mark the author's example values as printed (they are not your design choices).
- **Stage 4:** example schematics as component tables and net lists; measurement plots as approximate key-point tables with conditions.
- **Stage 4:** code listings verbatim in fenced blocks with language.
- **Stage 8:** design-equation summary and a parameter table for the reference design.

## Questions to ask
- Transcribe measurement plots as tables (L2) or only describe them (L1)?

## Split suggestion
- Usually one file; split only long design guides by chapter.

## Useful extras
- Equation summary; reference-design parameter table; BOM table.
