# Profile: generic

Use when no other profile fits (brochures, catalogues, theses, course notes, mixed technical reports).

## Signals
- None of the other profiles' signals dominate.

## Custom steps
- **Stage 2:** describe the document's structure in the classification card and ask which parts matter.
- **Stage 4:** apply the representation guide section by section; note recurring content types that a new profile could cover.
- **Stage 9:** if the document type is likely to recur, propose a new profile (file name and the Signals, Custom steps and Split suggestion sections) for the user to approve.

## Questions to ask
- What will the Markdown be used for (reference lookups, study notes, migration into a knowledge base)? The answer decides depth and extras.

## Split suggestion
- By chapter, only when large.

## Useful extras
- Glossary; key-numbers table; inconsistencies list.
