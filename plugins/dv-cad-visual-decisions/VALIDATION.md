# Validation scope

Version 1.0.0 is an evolving documentation-only skill. Static checks do not qualify CAD geometry, strength, fit, printability, safety, or physical performance.

Planned and completed checks for this local candidate are recorded by the preparing task. The skill should be exercised against at least these scenarios:

- a new hinge with an ambiguous closed-cover preference produces bounded alternatives and asks for a stable-ID choice;
- an identical repeated approved node is reused without a new prompt;
- an explicitly delegated selection records its criteria and scope;
- when visual tools are unavailable, the response discloses the limitation and gives a text fallback;
- print feedback that changes a mechanism returns to owner decision before a new CAD round.

No live FreeCAD/MCP execution, slicing, physical test, plugin installation, or printer action is part of this candidate validation.
