Its original Apache-2.0 [LICENSE](skills/freecad-mcp-operations/LICENSE) is retained unchanged. The [historical modification notice](skills/freecad-mcp-operations/references/provenance.md) describes that adaptation. This is attribution and licensing context only; it is not a Qwen runtime dependency or installation instruction.

Modified in 2.0.0: `skills/freecad-mcp-operations/SKILL.md` was reworked (MCP is the route for the user's live window; headless scripts and a separate GUI macro cover the rest) and `skills/freecad-mcp-operations/references/provenance.md` gained a 2.0.0 modification note. The retained LICENSE file is unchanged. Changes are marked as required by Apache-2.0 section 4(b).

## Original materials and images

Original package documentation and illustrations have no declared license in this release. The retained Apache-2.0 license applies only to the historically adapted operational skill material, not automatically to the other materials. External source links are attribution, not a claim of rights over those sources.

Ten AI-generated concept illustrations are retained with identical decoded pixels. Only their caBX/C2PA correlation metadata was stripped in public copies. These concepts are neither validated CAD nor evidence of mechanical or print performance.

## Public sanitization summary

Private source identifiers, private project names, personal conversation dates, installation history and source-archive correlation data are omitted. Historical preferences are represented as configurable defaults. Generic examples retain engineering intent without claiming private validation results. Original private source files were not modified.
